# Demobilder til nettsiden

Fritt lisensierte foto uten personer eller varemerker, brukt som
demonstrasjonsinnhold i telefonmockupen og utsnittene (Bjørka G12 er et
fiktivt lag). Begge lisensene tillater kommersiell bruk uten kreditering;
kildene står her for sporbarhet.
